# Text and languages

- The app is English-only unless the user asks for other languages; then follow `.claude/skills/add-locale/SKILL.md`.
- Every visible string (text, `placeholder`, `alt`, `aria-label`, titles) goes through `i18n._("Full English sentence", { values })` from `useLingui()` of `@lingui/react`; module-level labels use `msg({ id: "…" })`. No `<Trans>`, no `t` macro, no concatenation or template strings.
- Numbers and dates go through `#/libs/intl` (`formatDate(i18n.locale, value)`).
- After changing text: `bun run i18n:extract`; with other locales, fill every catalog, then `bun run i18n:check`.
- Full rules: `.claude/skills/i18n-lingui/SKILL.md`.
