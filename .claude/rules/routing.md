# Routing

- Every page lives under `src/routes/{-$locale}/`. Never add a route outside it.
- Link to internal pages with `LocalizedLink` from `#/libs/i18n`, never a bare `Link` or `<a>`. Its `to` is a plain string: check the route exists.
- Loaders read the language from `context.locale`, never from a cookie or `i18n.locale`.
- `src/routeTree.gen.ts` is generated by the Vite plugin. Never edit it; never run `tsr generate`.
- A page's `head` meta comes from `seo()` in `#/libs/seo` (title through `i18n._`, `path: match.pathname`).
- Unmatched paths and `throw notFound()` render `NotFound`, errors in a loader or a page render `ErrorPage` (`src/components/`, the router's defaults in `src/router.tsx`). A loader throws `notFound()` for a missing item; give a route its own `notFoundComponent` or `errorComponent` only when it needs a different message.
- Pages render inside `AppLayout` (`src/layouts/AppLayout.tsx`).
